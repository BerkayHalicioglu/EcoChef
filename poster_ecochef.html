📋 Overview

EcoChef addresses a common household problem: food waste caused by the inability to identify practical recipes from available ingredients — with no existing tool that works offline or supports multilingual input.

The project's core objective is to develop a cross-platform AI kitchen assistant capable of detecting ingredients via camera or text input, suggesting matching recipes in real time, and operating fully offline. Four goals guided the development: (G1) accurate single-frame ingredient detection using a mobile-deployable YOLO model, (G2) recipe suggestions delivered within 2 seconds online and under 5 seconds offline, (G3) full Turkish-language support via a built-in ingredient dictionary and LRU-cached translation, and (G4) a production-ready, containerised system with secure authentication and persistent user data.

The system employs YOLOv8 for real-time visual detection, Llama GGUF for on-device NLP inference, and the Spoonacular & TheMealDB APIs for access to 365,000+ recipes, backed by a FastAPI backend and React Native mobile client. Three research questions shaped the design: whether a single YOLOv8 model can reliably detect ingredients under varied conditions (RQ1), how effectively a quantised local LLM can substitute cloud-based NLP in resource-constrained environments (RQ2), and the impact of a multilingual ingredient dictionary on retrieval accuracy for non-English users (RQ3).

Key results include 3 deployed AI pipelines, 42 REST endpoints, sub-second offline inference, an 80+ entry TR↔EN ingredient dictionary, and full JWT security with PBKDF2-SHA256 (260k iterations).

🏆 Results, Takeaways & Contributions
Summary of Achievements
  • 3 independent AI pipelines (visual, text, hybrid) successfully integrated into a single mobile platform
  • Fully offline recipe suggestions achieved via quantised Llama GGUF — no internet dependency
  • 42 REST endpoints deployed with rate limiting, JWT blacklist, and PBKDF2-SHA256 security
  • Access to 365K+ recipes via dual API strategy with automatic fallback (Spoonacular → TheMealDB)
Key Takeaways
  • Combining on-device ML with cloud APIs creates a resilient system that degrades gracefully when offline
  • A lightweight ingredient dictionary outperforms raw translation alone for domain-specific NLP tasks
  • Containerised microservices (Docker Compose) significantly simplify cross-environment deployment
Contributions
  • Open hybrid AI architecture bridging real-time computer vision and local language models on mobile
  • Turkish NLP pipeline: 80+ ingredient dictionary + LRU-cached Google Translate for low-latency i18n
  • Full-stack reference implementation: React Native + FastAPI + MySQL + Docker, production-grade security
